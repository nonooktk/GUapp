## 6. 事故防止の仕組み（運用の約束）

- agent は commit・push・checkout・stash・reset・add -A をしない（`.claude/settings.json` の deny で拒否される。subagent にも効くことを実証済み）。commit と push はコーディネーターのみ。並行 agent は `isolation: worktree`（`.claude/worktrees/` に作られる。終了後 `git worktree remove --force`＋`rmdir /s /q`）
- main は PR 必須・gitleaks Required。直接 push は GH013 で拒否される
- テスト内のダミー値には `# pragma: allowlist secret` と `gitleaks:allow` の両方を最初から付ける。過去コミットの誤検出は `.gitleaksignore` の指紋
- 秘密スキャンの偽陽性で CI が赤になったら、行の内容を確認してマーカーを付ける（PR 6 本中 4 本で発生。本物の秘密は 0 件）
