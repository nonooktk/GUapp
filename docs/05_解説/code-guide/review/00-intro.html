0. この手引きの使い方

コードレビュー当日に、VS Code を見ながら説明するための手引きです。レビュワーが機能を 1 つ指定したら、その機能の章を開き、書いてある順に IDE でコードをたどります。各章の停留所には path:行 が出ているので、そのまま ⌘P に貼って開けます。

この章の数字と状態は 2026-10-03 時点です。基準にしたコミットは、ページ上部の「対象コミット」です。

レビューの進め方と、この手引きの章の並び

レビューは次の ①〜⑥ の順に進みます。各章（1〜10 章）の小見出しも、同じ順に並んでいます。

順レビューでやること各章の小見出し
①レビュワーが機能を 1 つ指定するこの章の「機能 × テストの早見表」と「指定のされ方の言い換え表」で章を選ぶ。各章の冒頭は「指定のされ方と 30 秒版」
②指定された機能を Frontend のコードから説明し、リクエスト先のバックエンドを示すまで② 画面からバックエンドへ
③対象のエンドポイントが、バックエンドでどう処理するか③ バックエンドの処理（エラーの分岐つき）
④response として戻ってきたところから、Frontend に表示されるまで④ 応答から表示まで
⑤対象の機能について、テストの仕様を 1 つ選び、そのテストコードが何を確認しているか⑤ テスト 1 本の説明
⑥テストの条件がテスト仕様書どおりか、レビュワーと突き合わせる⑥ 仕様書との突き合わせ。最後に「詰まりそうな質問」

当日は次の順に動きます。

  1. 指定を聞く。
  2. この章の早見表か言い換え表で、章を開く。
  3. 章の冒頭の「30 秒版」を言う。
  4. 順路（②③④）を IDE でたどる。停留所の「コピー」で path:行 を取り、⌘P に貼る。
  5. テスト 1 本（⑤）を説明する。
  6. 突き合わせ表（⑥）をレビュワーと見て、判定が緑（一致）でない行は、事実だけを言う。

VS Code の操作の早見

Mac の VS Code の既定のキー割り当てです。手元に入っている VS Code 1.139.1 の既定の定義と照らして確認しました。キー割り当てを自分で変えている場合は、この表と合いません。

操作キー（Mac の既定）使いどころ
ファイルを開く⌘Pファイル名の一部を打つ。path:行 を貼ると、その行で開く。停留所の「コピー」ボタンで path:行 を取れる
ファイル内の関数へ⌘⇧O同じファイル内で、関数名の一部を打って移動する
ワークスペース全体で関数・クラスへ⌘T別ファイルの関数名だけ分かるとき。言語サーバー（Python・TypeScript）が動いているときに使える
定義へ移動F12関数名にカーソルを置く。ノート PC では Fn を併用する設定のことがある
参照を探す⇧F12呼び出し元の一覧を出す
戻る・進む⌃-（進むは ⌃⇧-）F12 で飛んだあと、元の場所へ戻る。⌥← は既定では単語単位でカーソルを動かす操作で、戻る操作ではない

VS Code は、リポジトリのルート（GUapp）のフォルダを開いておきます。path:行 は、そのルートからの相対パスです。

F12 で飛べない箇所の探し方

場面やり方
BFF から FastAPI へBFF が FastAPI を呼ぶ箇所は URL の文字列なので、F12 では飛べない。⌘⇧F でパスを検索する。BFF の apiFetch が /api/v1 を自動で付けるため、BFF のコードに書かれたパスは /search/suggest のように /api/v1 が無い。FastAPI のデコレータ側も @router.get("/search/suggest" の形で、/api/v1 は付いていない。/api/v1/… で検索すると、テストや設計書が先に出る
FastAPI のルーターの登録build_protected_router が、/api/v1 の接頭辞を付けて、各ルーターを include_router で登録している。ルーターのファイルが分からないときは、ここを見る
Server Component から FastAPI へBFF を通らない機能（商品詳細・結果ページ・contents）は、lib/server/*.ts の関数 → apiFetch の順に F12 で進み、そのあとは上の「BFF から FastAPI へ」と同じ
テストを探すテスト ID で全文検索する。api のテストは、コメントに大文字（UT-SEARCH-05）、関数名に小文字とアンダースコア（ut_search_05）で出る。web のテストは、ファイル名（ut-web-09）に ID が入っている。⌘⇧F の検索欄の下にある「…」（検索の詳細を切り替える）で、検索対象のフォルダを apps/api/tests か apps/web/tests に絞れる
F12 が効かない言語サーバーがまだ起動していないことがある。⌘T で関数名を打つか、⌘⇧F で def 関数名・function 関数名 を検索する
