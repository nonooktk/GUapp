「購入ボタンを押す」「注文を確定する」

順路（停留所）

  1. OrderConfirm の submit。inflight.current を見て二重押しを止める。

    購入ボタンを押すと、まず画面側で二重送信を止めてから、注文の中身を作って送ります。

    次へ: F12 で createOrder の定義へ

  2. focus なしの例。範囲の開始行（createOrder の宣言）が出る。

    ブラウザからは Next.js の /api/orders にだけ送ります。

    次へ: ⌘P で apps/web/app/api/orders/route.ts を開く

  3. BFF の POST。バックエンドへ転送する proxyOrderRequest の行。

    Next.js が CSRF を確かめたうえで、FastAPI へ内部 HTTP で渡します。

    次へ: ⌘⇧F で create_order を検索

  4. ルーターの create_order。サービスを呼ぶ行（Python）。

    ルーターは受け取って返すだけで、判断はサービスに任せています。

    次へ: F12 でサービスの create_order へ

  5. サービスの入口。デッドロック時の再試行を含む呼び出し（Python）。

    ここから在庫の引き当て、決済、確定までを 1 つのまとまりとして進めます。
