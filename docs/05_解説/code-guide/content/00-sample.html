インライン参照

注文確定の中心は _confirm です。在庫の引き当ては reserve_stock が「在庫が数量以上あるときだけ減らす」条件付き更新で行います。 メソッドは Class.method 形式です（AppError.to_body、デコレータ付きの OrderCreateIn._strip）。 クラス単位でも引けます（PendingOrderInput）。

画面側では CheckoutForm（default export 関数）、 クライアント IP の解決は resolveClientIp、 Basic 認証は proxy、 Cookie 名の定数は CART_TOKEN_COOKIE（const 1 文）です。

行範囲で引く例: main.py の冒頭 30 行。 ファイル全体で引く例: ci.yml（YAML）。 同じ参照は 1 回だけ持たれます: _confirm（再掲）。

ラベル（事実・意見・注意）は CSS が自動で付けます。本文側で「事実:」と書く必要はありません。

Q&A

0〜1分二重注文はどう防いでいますか

冪等キーの一意制約と、カートの「注文済み」への切り替えで防いでいます。実装は _confirm です。

追撃: 同時に 2 本届いたらどうなりますか

先に書き込んだ側が成功し、後の側は既存の注文を返されます。

1〜2分もう 1 つの質問（初期は閉じている）

開閉は素直な details です。

FROM orders AS o
