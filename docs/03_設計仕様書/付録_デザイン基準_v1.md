# 付録: GUapp デザイン基準 v1（2026-09-18）

担当: キキ＆ララ（UI/UX）。`付録_GUサイト調査_20260918.md` の実測結果を、GUapp P1 の6画面（設計仕様書 6.2〜6.8、DS-SCR-001〜006）に翻訳したデザイン基準。マイメロディ（web実装）は本書のトークンを `apps/web/app/globals.css` にそのまま写し、部品仕様に沿って `apps/web/components/*` を更新する。

## 1. 目的と適用範囲

- 適用範囲: P1 の SCR-001〜006（ホーム／商品一覧／商品詳細／カート／注文手続き／注文確認・完了）。Wave 0〜1 で SCR-001〜004、Wave 2 で SCR-005〜006 に適用する。
- 対象外: GU のロゴ・商品写真・文言・アイコン素材そのもの。これらは複製せず、GUapp 独自のプレースホルダー／テキストで代替する。
- 現状の `apps/web` は Tailwind の仮置き（グレー基調・`Hiragino Sans` フォールバックのみ）。本書はこれを GU らしい黒×白×ピルのトーンに更新するための基準を定める。

## 2. トークン

`apps/web/app/globals.css` に CSS 変数として定義する（`@theme inline` ブロックに追加、または `:root` に定義して Tailwind から `var(--color-*)` で参照）。

### 2.1 色

| 変数名 | 値 | 用途 | 根拠 |
| --- | --- | --- | --- |
| `--color-bg` | `#FFFFFF` | ページ背景 | 調査1章 |
| `--color-fg` | `#1B1B1B` | 本文・見出し・価格の基本文字色 | 調査1章（GU実測の濃いグレー黒） |
| `--color-fg-muted` | `#595959` | 補助文字（カテゴリ表記・注記・キャプション） | 調査実測 `#6A6A6A` はコントラスト5.4:1でぎりぎりのため、GUapp では一段濃い `#595959`（コントラスト約7.5:1）を採用し余裕を持たせる（**この値は調査結果からの補正案**） |
| `--color-line` | `#E5E5E5` | 罫線・区切り線 | 調査で明確な罫線値が取れなかったため一般的な薄灰を採用（**推定案**） |
| `--color-primary` | `#1B1B1B` | 主ボタンの背景 | 調査1章実測 |
| `--color-primary-fg` | `#FFFFFF` | 主ボタンの文字 | 調査1章実測 |
| `--color-accent` | `#EE0000` | 価格の強調表示（セール・会員限定価格） | 調査1章実測 |
| `--color-danger` | `#C4232B` | エラー文言・削除確認 | GU実測のエラー色は未確認のため、`--color-accent` よりやや暗い赤でコントラスト7:1超を確保した補正値（**推定案**） |
| `--color-success` | `#1B7A3D` | 成功トースト（カート追加成功等） | GUapp 独自定義（GU実サイトに対応要素なし。**推定案**） |
| `--color-badge` | `#1B1B1B` | 在庫切れバッジ・カート点数バッジの背景 | 在庫切れバッジは調査で未確認のため、GUapp 現行実装（`ProductCard.tsx` の `bg-gray-900/80`）を踏襲し `--color-fg` と揃える |

### 2.2 書体

- **本文・見出み共通ファミリー**: `Noto Sans JP`（Google Fonts、`next/font/google` で読み込み）。フォールバック列: `"Noto Sans JP", "Hiragino Kaku Gothic ProN", "Hiragino Sans", Meiryo, sans-serif`。
  - 理由: GU 実サイトの日本語表示は結局 Hiragino/Meiryo 系にフォールバックしており、独自書体 `GUNextLight`／`GUNextRegular` は有償・非公開のため複製しない。無償で最も近い雰囲気（角の少ないシンプルなゴシック）を持つ `Noto Sans JP` を採用する。
- **見出し・商品名・カテゴリ見出しの役**: `font-weight: 300`（Noto Sans JP は Thin=100〜Black=900 まで揃っており 300 = Light が使える）。
- **本文・注記の役**: `font-weight: 400`。
- **価格の役**: `font-weight: 700`。
- CSS変数: `--font-heading: "Noto Sans JP", ...`／`--font-body: "Noto Sans JP", ...`（同一ファミリーだがウェイトで役割分担するため変数上は分けておき、将来の差し替えに備える）。

### 2.3 サイズ階層

実測（調査2章）に合わせて次の階層を採る。

| 変数名 | 値 | 用途 |
| --- | --- | --- |
| `--text-xs` | 12px | キャプション・注記（税込表記など） |
| `--text-sm` | 14px | 補助文字・ボタン内ラベル・フォーム入力 |
| `--text-base` | 16px | 本文・商品名 |
| `--text-lg` | 20px | 小見出し・商品カードの価格 |
| `--text-xl` | 24px | セクション見出し・カート見出し |
| `--text-2xl` | 32px | ページ見出し（商品詳細の価格など、必要な場面のみ） |

- 行間: 見出し系は `line-height: 1.4`、本文・価格は `line-height: 1.5`（調査2章の実測比率に合わせる）。
- 字間: 見出し・価格に `letter-spacing: 0.02em`（実測 0.48px 相当。Tailwind では `tracking-wide` 相当のカスタム値として定義）。本文は `normal`。
- 余白の基準: **4の倍数**（4/8/12/16/24/32/48px）。GU実測の縦ギャップ24pxもこの並びに一致する。
- ブレークポイント: `375px`（モバイル基準幅）／`768px`（タブレット）／`1280px`（デスクトップ基準幅）。Tailwind の `sm`(640)/`md`(768)/`lg`(1024)/`xl`(1280) のうち、`md` と `xl` を主に使う。
- 角丸: `--radius-pill: 999px`（ボタン・チップ）／`--radius-sm: 8px`（画像コンテナ・カード。GU実測ではカードに角丸が無いが、GUapp は既存実装で `rounded-lg` を使っており大きな見た目の破綻がないため維持する）。
- 影: 既定は `none`。モーダル（`ConfirmDialog`）のみ `--shadow-modal: 0 10px 30px rgba(0,0,0,0.2)`（既存実装の `shadow-xl` を踏襲）。
- タッチターゲット最小: **44px**（アイコンボタン）。主要CTAは **52px高**（調査3章実測に合わせる。現行実装の `h-12`=48pxから `h-13`相当への微調整が必要。Tailwind に無い値のため任意クラス `h-[52px]` を用いる）。

## 3. 部品仕様

各部品は「通常／ホバー／フォーカス／無効／処理中」の状態を持つ。フォーカスは全部品共通で `outline: 2px solid var(--color-fg); outline-offset: 2px;`（現行実装の `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-gray-900` を色トークンに置き換えるだけで踏襲可）。

### ボタン
- **primary**（例: カートに入れる／注文を確定する）: 背景 `--color-primary`・文字 `--color-primary-fg`・角丸 `--radius-pill`・高さ52px・`font-weight:700`。ホバー: 背景を`#000000`に暗く。無効: 背景 `#D9D9D9`・文字 `#8C8C8C`・`cursor:not-allowed`（GU実測の無効表現は未確認のため、既存実装のグレーアウトを継続=**推定案**）。処理中: ラベルを「処理中…」に差し替え、`aria-busy="true"`、クリック不可。
- **secondary**（例: お買い物を続ける／戻る）: 背景`--color-bg`・文字`--color-fg`・枠線1px `--color-fg`・角丸pill・高さ52px。ホバー: 背景`--color-line`。
- **ghost**（例: フッターリンク、テキストリンク的な操作）: 背景なし・文字`--color-fg`・下線はホバー時のみ。

### 入力欄・セレクト
- 高さ44px以上、角丸`--radius-sm`（GU実測に無いため一般的なフォーム慣習を採用=**推定案**）、枠線1px `--color-line`、フォーカス時は枠線を`--color-fg`に。
- エラー時: 枠線`--color-danger`、入力欄直下に赤文字メッセージ（`role="alert"`、`--text-sm`）を表示。ラベルは項目名の上、必須項目には「（必須）」のテキストラベルを付ける（アイコンのみに頼らずスクリーンリーダーで判別可能にする）。

### 商品カード
- 画像アスペクト比 **3:4**、列間ギャップは横**0px〜8px**（GU実測は0pxだが視認性のため8pxを推奨=**補正案**）、縦ギャップ24px。
- 名称は最大2行（`line-clamp-2`）、価格は`--text-lg`・`font-weight:700`・`--color-fg`。セール・会員限定価格時のみ`--color-accent`。
- 在庫切れ: 画像左上に`--color-badge`背景・白文字のバッジ「在庫切れ」（既存実装踏襲）、価格欄も「在庫切れ」テキストに差し替え価格を隠す。
- 色チップ: 商品名の下に小さな円（実測未確認のため直径16px程度を推奨=**推定案**）を最大5件、超過時は「+N」表記。

### 価格表示
- 通常価格: `¥1,990`（半角数字・カンマ区切り、既存 `formatYen` を継続使用）。
- 税込表記: 価格の右に小さく`（税込）`（`--text-xs`・`--color-fg-muted`）。既存 `Price` コンポーネントの `taxNote` をそのまま使う。
- 会員限定・セール価格: `--color-accent` に加え、直下に注記テキスト（例:「9/24まで会員特別価格」相当の文言。GUapp では「セール価格」等プロジェクト内の文言に置き換える）。

### バッジ（カート点数）
- ヘッダーのカートアイコン右上に円形バッジ。背景`--color-badge`（実装は現行の赤`bg-red-600`のままでも良いが、トークン上は`--color-accent`を流用して統一する）、白文字、最小幅20px、`99+`で丸め表示（既存実装踏襲）。

### トースト
- 現行実装（`Toast.tsx`）の構造を維持しつつ、色をトークン化: success系は`--color-success`、error系は`--color-danger`、info系は`--color-fg-muted`をベースにした薄い背景＋濃い文字。位置・自動消滅時間（既定4000ms）は現状維持。

### 確認ダイアログ
- 現行実装（`ConfirmDialog.tsx`）の構造・フォーカストラップ・Escape対応をそのまま維持。ボタンをsecondary（キャンセル）とprimaryまたはdanger（確定）のトークンに置き換えるのみ。danger時は背景`--color-danger`。

### ヘッダー
- **1280px**: 左ロゴ、ロゴ右にWOMEN/MEN/KIDS相当のカテゴリタブ（P1では非表示または簡略でも可、既存実装のメニュー導線で代替）、右端に検索・お気に入り・カート（バッジ付き）・会員の4アイコン（44×44px）。GU実測は非固定ヘッダーだが、GUapp は既存実装ですでに`sticky top-0`。**この点はGU実サイトとの意図的な差**として維持する（カート操作の視認性を優先。7章参照）。高さ64px（現行`h-14`=56pxから微調整の余地あり、必須ではない）。
- **375px**: 1行目にロゴ・検索・アイコン群、必要ならカテゴリタブは2行目（P1では簡略化可）。現行実装の「≡ 左・ロゴ中央・アイコン右」の1行構成は、GU実サイトの「ロゴ左・検索中央・アイコン右＋カテゴリ2行目」と異なるが、P1の画面数・情報量では現行構成のままで問題ない（変更不要、差分メモの対象外）。

### フッター
- 現行の5リンク構成（企業情報・利用規約・プライバシー・特商法・FAQ）を維持。文字色を`--color-fg-muted`ベースに統一。

### パンくず
- P1では商品一覧・商品詳細に「カテゴリ名 > 中カテゴリ」程度の簡易パンくずをテキストリンクで表示（`--text-sm`・`--color-fg-muted`、区切り記号`>`）。GU実サイトでは未確認だったため、要求仕様書の一般的なEC慣習に基づく**推定案**。

### 固定購入バー（375px）
- 現行実装（`PurchasePanel.tsx` の `sticky-bar`）を維持。**GU実サイトには存在しない要素だが、設計仕様書6.5・テスト設計書ST-F005-03で明示的に要求されているため実装を継続する**（7章の意図的な差として明記）。

### 「もっと見る」ボタン
- secondaryボタンの横幅いっぱい版。クリックで24件ずつ追加読み込み（設計書6.4の記載どおり）。GU実サイトの挙動は未確認のため、設計書の仕様をそのまま踏襲する。

### 警告文（在庫不足等）
- `role="alert"`、`--color-danger`文字、先頭に`⚠`（既存実装踏襲）。

## 6. アクセシビリティ基準

- コントラスト比: 本文・ボタンとも**4.5:1以上**を必須とする。`--color-fg`(#1B1B1B)は白背景で17.6:1、`--color-fg-muted`(#595959)は約7.5:1、`--color-accent`(#EE0000)は太字20px以上でのみ使用（3:1基準を満たせば可、通常文字サイズでは使わない）。
- フォーカス可視化: すべての操作可能要素に`outline`を必須表示（`focus-visible`のみで良い。マウスクリック時に出す必要はない）。
- キーボード操作: ボタン・リンク・フォーム要素はTab移動で到達可能、モーダル（`ConfirmDialog`）はフォーカストラップ＋Escapeで閉じる（実装済み）。
- `aria-*`: 数量セレクト・色/サイズチップに`aria-label`（実装済み）、在庫状態は`aria-live="polite"`（実装済み）、エラー・警告文は`role="alert"`（実装済み）。SCR-005のフォームエラーも同じ`role="alert"`パターンに統一する。

補足（2026-09-18 適用時の確定事項。コーディネーター記載）:
- コントラスト 4.5:1 の対象は**操作可能な状態**のテキスト。無効（disabled）状態は WCAG 1.4.3 の適用除外とし、3 章の `#D9D9D9`／`#8C8C8C`（2.38:1）のままでよい。
- チップ・入力欄など**非テキスト UI の境界線**は WCAG 1.4.11 に従い隣接色と 3:1 以上。未選択チップの枠線は `--color-line`（1.2:1）ではなく `--color-fg-muted` を使う（適用時の判断を基準に取り込む）。入力欄の枠線も同じ扱い。

## 7. GU 実サイトとの意図的な差

| 項目 | GU実サイト | GUapp | 理由 |
| --- | --- | --- | --- |
| ヘッダーの固定 | 非固定（`position: static`） | 固定（`sticky top-0`） | カート操作・巡回のしやすさを優先。既存実装を維持 |
| 商品詳細375pxの下部固定バー | 無し | 有り | 設計仕様書6.5・テスト設計書ST-F005-03で明示要求されているため実装 |
| 価格・見出しの専用書体 | `GUNextRegular`／`GUNextLight`（有償・独自） | `Noto Sans JP`（Google Fonts） | 独自書体を複製しないため無償フォントに置き換え |
| 商品カード列間ギャップ | 0px | 8px | 演習用の見やすさを優先した簡略化 |
| 補助文字色 | `#6A6A6A`（コントラスト5.4:1） | `#595959`（コントラスト7.5:1） | アクセシビリティ基準に余裕を持たせるための補正 |
| パンくず・エラー表示・在庫切れバッジの正確な意匠 | 未確認 | 一般的なEC慣習＋既存実装を踏襲 | GU実サイトで裏取りできなかったため推定で埋めた |

複製していないもの: GU のロゴ画像・商品写真・商品名やキャッチコピーなどの文言・アイコン素材（SVGそのもの）・CSSファイル。GUapp は色・書体・寸法・配置・振る舞いの「規則」のみを踏襲している。
